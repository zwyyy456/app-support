# zcompare 宣传首页草稿

直接打开 `index.html` 即可预览。默认深色，页头可以切换浅色。在网页地址后加 `?theme=light` 可以直接打开浅色版。「查看比较示例」跳到本页的文本、图片和二进制截图。

## 截图素材

两种配色共用同一组浅色 App 截图。网站素材位于 `assets/`，已移除文件路径栏中的本机目录。各屏幕宽度均按原比例显示完整窗口。

| 文件 | 展示内容 |
| --- | --- |
| `text.webp` | 文本差异与空白占位。 |
| `image.webp` | 并排图片及对应的透明度变化区域。 |
| `binary.webp` | 固定偏移的字节高亮和 ASCII 栏。 |

更新素材时保留窗口原始比例，去掉私人路径，按图片实测尺寸更新对应 `img` 的宽高和说明。
